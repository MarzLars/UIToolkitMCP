# USS selectors

Learn how to use USS selectors by examples.

Read time 1 minuteLast updated 2 months ago

---

Selectors decide which elements that USS rules affect.

USS supports a set of simple selectors that are analogous, but not identical, to simple selectors in CSS. A simple selector matches elements by element type, USS class, element name, and wildcard.

You can combine simple selectors into complex selectors, or append [pseudo-classes](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/pseudo-classes) to them to target elements in specific states. USS supports descendant, child, and multiple complex selectors.

| **Topic** | **Description** |
| --- | --- |
| [Type selectors](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/type) | Match elements based on their element types. |
| [Name selectors](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/name) | Match elements based on the name of an element. |
| [Class selectors](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/class) | Match elements that have specific USS classes assigned. |
| [Universal selectors](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/universal) | Match any element. |
| [Descendant selectors](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/descendant) | Match elements that are descendants of another element in the visual tree. |
| [Child selectors](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/child) | Match elements that are children of another element in the visual tree. |
| [Multiple selectors](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/multiple) | Select elements that match all the simple selectors. |
| [Selectors list](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/list) | Create a comma-separated list of selectors that share the same style rule. |
| [Pseudo-classes](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/pseudo-classes) | Use pseudo-classes with selectors to target elements that are in a specific state. |
| [Selector precedence](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/selector-precedence) | Understand USS precedence when multiple USS rules target the same elements. |
| [Check pseudo-state of a control](/en-us/engine/6000.6/manual/uitoolkits/uielements/uie-uss/selectors/check-pseudo-state) | Check the pseudo-state of a control to ensure styles apply correctly. |
