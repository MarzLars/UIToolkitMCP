# UI Toolkit

The latest UI system, designed for optimized performance across platforms and inspired by standard web technologies. Use UI Toolkit to create extensions for the Unity Editor, and to create runtime UI for games and applications.

Read time 2 minutesLast updated 2 months ago

---

UI Toolkit is a collection of features, resources, and tools for developing user interface (UI).

| **Topic** | **Description** |
| --- | --- |
